# 使用说明

[返回项目首页](../README.md) · [开发文档](开发说明.md)

## 下载与启动

Windows x64 便携包文件名为 `qingchuan-0.1.0-windows-x64.zip`。已完成本地候选包构建，GitHub Release 尚未发布；发布后可在[版本页面](https://github.com/snowcgj/qingchuan/releases)获取。现阶段可按[首页的源码运行步骤](../README.md#从源码运行)使用。

拿到便携包后，解压整个文件夹，双击 `启动轻传.cmd`。不要单独移走或删除 `runtime` 等目录；它们让程序在没有另装 Node.js 的电脑上运行。

电脑浏览器打开 `http://127.0.0.1:4317`，点击「开启接收」。手机与电脑连接同一 Wi-Fi 或热点，用相机或浏览器扫码，打开页面后点击「连接这台电脑」。

首次启动可能出现 Windows 防火墙提示，需要允许当前局域网访问。多个网络同时连接时，在电脑页面选择手机所在的网络地址。切换网络后刷新页面并重新配对。

## 收发照片

| 方向 | 发送端 | 接收端 |
| --- | --- | --- |
| 手机 → 电脑 | 手机点击「发送到电脑」，多选照片并发送 | 电脑点击「接收手机照片」预览、下载 |
| 电脑 → 手机 | 电脑点击「发送到手机」，选择或拖入照片 | 手机点击「接收电脑照片」预览、下载 |

连接一次即可切换方向，也支持同时发送。收到照片时会打开接收页；如果正在准备或发送照片，则保留当前操作。

「清除已送达」只清理发送记录和预览，保留待发送或失败的照片、原始文件和对方收到的内容。「清空已接收照片」会移除当前页面的接收列表，请先下载保存。

## 手机保存与下载确认

- **一张照片**：点击「下载原图」；没有保存提示时，点击预览图打开原图，再长按保存。
- **多张照片**：优先使用「打包下载（ZIP）」，只产生一个下载任务，解压后是全部原图。
- **多个独立文件**：使用「分别下载原图」。这会产生多个任务，浏览器仍可能逐张要求确认，网页无法关闭这些原生弹窗。

轻传不会把“发起下载”当作“已保存成功”。请到浏览器下载记录、文件管理或相册确认结果。ZIP 未解压前不会作为多张照片出现在相册；下载后的图片是否进入相册取决于手机和浏览器。

工具不会主动重新编码、缩放或压缩图片；手机系统的选择器仍可能转换特殊格式。浏览器无法预览 HEIC 等格式时，可以尝试下载。

## 常见问题

**手机打不开页面？**

确认两台设备在可互访的网络里，检查电脑所选网卡地址和防火墙是否放行。访客 Wi-Fi、设备隔离或 VPN 可能影响访问。也可尝试让电脑连接手机热点。

**显示已收到，却找不到下载文件？**

页面里显示的是预览。请点单张「下载」，观察浏览器保存提示；再检查下载记录。部分内置浏览器需要使用原图页长按保存。

**点“分别下载”后逐张弹窗？**

浏览器正在确认多个下载任务。改用 ZIP 可以合并为一个任务，但保存后需要解压。

**临时链接过期？**

重新发送照片生成新链接。服务重启或下载缓存淘汰也会让旧链接失效。

**手机刷新后怎么继续？**

有效会话内可重新点击连接，或扫描电脑的新二维码。同页扫描新配对链接会切换会话。刷新会清掉网页接收列表，请提前保存。

## 数据与使用边界

```text
电脑浏览器 ←→ 电脑上的本地服务 ←→ 手机浏览器
                    ├─ 内存配对信息
                    └─ 有时限的下载副本
```

- 当前支持图片。单张最多 50 MiB，每批最多 100 张、合计 200 MiB；每个页面接收容量最多 200 MiB。
- 每个会话一个电脑页面和一个手机页面，两端均可收发。配对凭证有效期为 30 分钟，重新配对会关闭旧连接。
- 照片不上传云端，也不写入服务端磁盘。下载副本仅在电脑内存缓存，默认 15 分钟有效，空间不足时较早副本可能提前失效；全局预算为 200 MiB，停止服务立即清空。
- 下载链接含随机凭证，请勿转发。清空页面列表不会立即撤销已生成的临时链接，它们仍按上述期限清理。
- 当前 HTTP / WebSocket 没有 TLS 加密，只适合自己的可信局域网。SHA-256 用于完整性校验，不代表加密。
- 传输时保持页面打开，手机不要锁屏。暂不提供后台传输、断点续传、公网中转、视频、任意文件或文件夹传输。

当前便携包面向 Windows x64。小米手机配合必应内置浏览器的连接、双向传图和单张下载已有实机反馈；其他手机、浏览器和 iOS 的保存表现仍待实测。

## 结束使用

先保存需要的照片，再双击 `停止轻传.cmd`；命令行启动时也可按 `Ctrl+C`。更新版本前，先停止旧版服务。
